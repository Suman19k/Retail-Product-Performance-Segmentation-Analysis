# 📊 Retail Product Performance & Segmentation Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing a retail dataset using advanced SQL techniques to uncover insights related to product performance, revenue trends, and customer engagement.

The analysis includes multiple business queries, segmentation techniques, and data visualizations to better understand key drivers of business growth.

---

## 🎯 Objectives
- Analyze retail data using SQL
- Identify top-performing products
- Understand revenue distribution and trends
- Perform product segmentation based on value
- Visualize insights for better decision-making

---

## 🛠️ Tools & Technologies
- SQL (SQLite)
- Python (Pandas, Matplotlib)
- Google Colab / Jupyter Notebook

---

## 🗂️ Dataset Description
The dataset consists of multiple tables:

- **info** → Product details  
- **finance** → Pricing, discounts, revenue  
- **reviews** → Ratings and review counts  
- **traffic** → Product visit data  
- **brands** → Brand information  

---

## 🔍 Key Analysis Performed

### 📈 Business Queries
- Top products by average sales price  
- Top products by revenue  
- Most purchased products  
- Most reviewed products  
- Highest rated products  
- Most visited products  

---

### ⚙️ Advanced SQL Techniques
- Joins across multiple tables  
- Common Table Expressions (CTEs)  
- Window Functions (`RANK()`, `SUM() OVER()`)  

---

### 🧠 Segmentation Analysis
- Products categorized into:
  - High Value  
  - Medium Value  
  - Low Value  
- Based on revenue and engagement metrics  

---

### 📊 Visualizations
- Line charts (trend analysis)  
- Scatter plots (relationship analysis)  
- Donut charts (distribution)  
- Dotted graphs (cumulative trends)  

---

## 📌 Key Insights
- A small number of products contribute to the majority of revenue (Pareto Principle)  
- High review count does not always indicate high revenue  
- Most products fall under the low-value segment  
- Premium products generate higher revenue  
- Strong relationship observed between price and revenue
